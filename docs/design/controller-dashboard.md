# 控制器 Dashboard 实现

采用用户确认的 B 方案：设备图与逐项映射并排，完整链路信息在下方默认展开并允许收起。
原型来源：本地分支 `codex/prototype-controller-dashboard`，提交 `965a006`，
`Sources/JoyHarness/DashboardPrototype/`。原型代码不进入实现分支。

1. 用户目标：确认设备是否可用、当前输入模式和下一步动作；查看真实按键反馈并进入映射设置。
2. 范围：Dashboard 控制器概览常驻；连接能力、权限、语音和震动测试位于可收起的链路区域。
3. 层级：设备与连接/模式摘要优先；逐项映射是参考信息；按键高亮和输入读数是即时反馈。
4. 重点：复用控制器资源，原生控件和系统材质；青色仅用于按下，状态始终带图标和文字。
5. 状态：未连接提供蓝牙/USB 指引；状态读取失败或过期不冒充断开或可用；权限/适配器阻断就近说明；
   原生模式明确映射暂停；未知能力显示未知，缺少震动不使整个链路变为故障。
6. 文案：中文/English 使用相同结构；长设备名、映射和音频名允许换行；固定窗口内超出内容纵向滚动。
7. 复用：既有 4/8/12/16/22/32 间距、7pt 圆角、系统字体、SF Symbols 和控制器 PNG；
   新的窗口/图解尺寸集中为组件 token，不在业务视图散落常量。

所有数据来自现有运行时；保留八类控制器、Joy-Con 横竖握与端点信息、全部独立输入和现有 Settings。
不显示任务列表、任务标题、槽位卡片或任务状态。槽位名称只作为映射动作名称出现。
震动测试采用有限的硬件反馈，不更改任务状态，也不启动持续震动循环。

## Token 与可访问性

`DashboardStyle` 集中组件尺寸、4/8/12/16/22/32pt 间距、7pt 圆角与 120ms 释放动画。
主窗口内容区固定为 744×600pt，不允许拖动改变宽高；超出内容使用纵向滚动。
组件仍保留 700pt 以下的纵向布局，供隔离渲染检查复用。
设备图高度收紧为 220pt，映射区为 240pt；状态摘要独占整行，详情仍可滚动查看。
`input` 是语义色：亮色 #08758D 对白色为 5.33:1，深色 #22D3EE 对 #1E1E1E 为 9.22:1；
正文使用系统 primary/secondary，按下状态还提供图标和文字，不依赖颜色。
按下不播放动画；释放最多 120ms；读取系统 Reduce Motion 时移除淡出动画。
SF Symbols 与原生按钮、Picker、DisclosureGroup 提供键盘焦点与无障碍语义。

Joy-Con 高亮锚点以现有 1024×1536 PNG 为坐标基准，横握和组合由同一组坐标变换生成。
DualShock 缺少专用图、generic 未知设备使用系统控制器图标，不猜测型号。

## 验证方法与边界

- 单元测试覆盖无震动设备的正常连接、未知/过期状态、未知权限/电量、原生模式暂停、
  断开/换设备/模式切换清除输入、原生 Joy-Con 只发布物理输入、有限震动与无引擎失败。
- 原生视图审查命令：`DASHBOARD_RENDER_DIR=/tmp/joy-dashboard-renders swift test --filter DashboardRenderingTests`。
  覆盖八类设备的中文亮色宽布局、英文深色高对比窄布局、单只 Joy-Con 横竖握，以及未连接/过期状态；
  数据与偏好均隔离，渲染器只存在于测试 target。
- 渲染审查需单独运行：它占用主线程，与 socket/按键重复计时测试并发会造成超时。
- 本机实测小米遥控器连接、真实电量/权限/语音状态、默认展开详情及禁用震动测试。
  已通过鼠标收起、Tab + Space 展开详情，以及配置入口、Tab + Space 打开原生映射 Picker。
- 其余设备通过真实组件的隔离渲染与输入逻辑测试验证；本轮未连接对应实物进行硬件震动测试。
- 无障碍树、键盘控件与 Reduce Motion 分支已检查；没有宣称完成 VoiceOver 听读或硬件级 <16ms 延迟测量。

最终检查：`task ci` 通过（Swift 测试汇报 193 项，其中视觉审查默认跳过并单独运行；Python 24 项、麦克风驱动检查、shellcheck、Release 构建均通过）。最终本机签名应用通过 `scripts/build_and_run.sh --verify` 启动，12 项遥控器映射均出现在无障碍树中，并观察到真实语音键释放反馈。

紧凑尺寸更新会在主窗口创建后一次性设置并保存尺寸，避免系统恢复旧尺寸覆盖 SwiftUI 默认值；设置窗口不参与迁移，后续启动仍正常恢复窗口。
